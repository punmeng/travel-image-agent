    Threads 貼文草稿

    編輯・複製・分享

    使用 Foundry + MAI 依日程產生手寫故事圖。產圖時間依服務狀態而異，會產生模型用量費用。

    按下按鈕後開始產生；不會自動發布到社群。

    下載 PNG 圖片 share to Instagram

    先下載圖片，再至社群 App 選擇圖片上傳。若裝置支援檔案分享，產生完成後可另外按「開啟裝置分享」。圖片中的細小文字請先校對。

    草稿可編輯；圖片依左側固定行程產生。
    在 Threads 開啟文字草稿

    Threads 草稿只帶文字；下載 PNG 後，請在 Threads 手動附上圖片。

    如何分享到 Instagram / Threads？

    Instagram：下載 PNG → 開啟 Instagram App → 建立貼文或限時動態並選擇圖片 → 貼上已複製的文案。此網頁不會直接附圖至 Instagram 或自動發布。

    Threads：按「在 Threads 開啟文字草稿」，再手動選擇下載的 PNG。裝置分享可用的 App 取決於瀏覽器與裝置。

    原生 Instagram Stories 整合需 Android / iOS App；自動發布 API 另需 Meta 帳號授權、發布權限與可供 Meta 存取的圖片網址，這個本機範例未實作。

    官方說明： Threads 文字草稿 · Instagram Stories · 裝置檔案分享
